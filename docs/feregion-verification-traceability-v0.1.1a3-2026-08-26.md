## Purpose

This document identifies how each current requirement is assessed. It separates the intended assessment method from the observed release result. The delivery-side verification record is the authority for commands that actually ran, their environment, skips, failures, and limitations. A workflow definition or test path is not itself a passing verification result.

## Release evidence record

For each delivered version, the external verification record must state the exact source identity, command or assessment, environment, observed result, skipped or unavailable scope, and known limitation. The quality-assurance document defines the release gates that consume these records.
